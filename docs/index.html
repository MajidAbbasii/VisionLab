THE PROJECT

Built to learn. Made to explore.

01 / RESEARCH
⌘

A practical computer vision lab

VisionLab brings model training, evaluation, hyperparameter optimization and inference together in one reproducible project. Python powers the research workflow; .NET provides a separate ONNX inference application.

Explore the model →
02 / PIPELINE
DATA→YOLO11→ONNX→INFERENCE

One model, multiple runtimes

Train and evaluate with Ultralytics, export a fixed-shape ONNX model, then run it with ONNX Runtime in .NET or directly in this browser demo.
