# COCO category-name attribution

`datasets/classes.txt` contains the 80 COCO object-category names used by the VisionLab detector. It is a small category-name list derived from the COCO annotation/category metadata; the Windows package does not include COCO photographs, annotation JSON, masks, or other dataset payloads.

COCO's published terms identify its annotations and associated website content as licensed under the Creative Commons Attribution 4.0 International license (CC BY 4.0). Preserve this attribution and the license link when redistributing the category list:

- Dataset: Microsoft COCO — Common Objects in Context
- Dataset/paper reference: Tsung-Yi Lin et al., “Microsoft COCO: Common Objects in Context,” ECCV 2014, https://arxiv.org/abs/1405.0312
- Dataset terms: https://cocodataset.org/dataset/termsofuse.htm
- License: Creative Commons Attribution 4.0 International, https://creativecommons.org/licenses/by/4.0/
- Included derived material: category names only (`datasets/classes.txt`); no images or annotation records

The underlying Flickr-hosted photographs have separate copyright and Flickr terms. No image rights are granted by this category-name notice. Do not add COCO images or annotation payloads to a release until their specific redistribution rights have been reviewed.
