YOLO11n Object Detector

VisionLab's selected model is a compact YOLO11n object detector fine-tuned for an educational experiment on COCO-derived data. It is intended for learning, experimentation and evaluation—not safety-critical, medical, biometric or other high-impact decisions.

Training and evaluation

The selected fine-tuned checkpoint is models/trained/best_coco2017_expanded_epoch1.pt. Its metadata records Ultralytics 8.4.215, the datasets/coco2017_expanded.yaml configuration, seed 20261120, image size 640, batch size 4 and a planned 100-epoch budget. The run was intentionally stopped after 10 epochs; the selected best checkpoint is from epoch 1.
